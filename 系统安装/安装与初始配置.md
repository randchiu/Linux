# 二、Win11下安装Linux子系统（WSL2）
## 安装在C盘（使用cuda推荐装在C盘）
1. 启用或关闭windows功能--->勾选**适用于Linux的windows子系统**和**虚拟机平台**
2. 管理员权限打开windows终端，输入
   ```
   wsl --update
   ```
4. 输入以下命令设置默认版本为wsl2
   ```
   wsl --set-default-version 2
   ```
5. 输入以下命令查看可安装的Linux发行版,并按提示选择相应版本安装，安装完成后创建**用户名**和**密码**
   ```
   wsl.exe --list --online
   wsl.exe --install <Distro>
   ```
## 安装在D盘（先默认装在C盘）
1. 关闭wsl，并列出当前所有安装的发行版
  ```
  wsl --shutdown
  wsl -l --all -v
  ```
2. 导出发行版至D盘(wsl --export <DistributionName> <FileName.tar>)
```
wsl --export Ubuntu-22.04 D:\WSL-Ubuntu22.04.tar
```
3. 删除原有的发行版
```
wsl --unregister Ubuntu-22.04
```
4. 导入发行版到新的位置(wsl --import <DistributionName> <InstallLocation> <FileName.tar>)
```
wsl --import Ubuntu-22.04 D:\WSL-Ubuntu22.04 D:\WSL-Ubuntu22.04.tar --version 2
```
5. 删除tar文件
```
del D:\WSL-Ubunru22.04.tar
```
## 安装后基本配置
1. 更改ubuntu软件仓库镜像源，**更改前备份**。在 Ubuntu 24.04 之前，Ubuntu 的软件源配置文件使用传统的 One-Line-Style，路径为 /etc/apt/sources.list；从 Ubuntu 24.04 开始，Ubuntu 的软件源配置文件变更为 DEB822 格式，路径为 /etc/apt/sources.list.d/ubuntu.sources。可进入网站https://mirrors.tuna.tsinghua.edu.cn/help/ubuntu/ 按提示操作。
2. 更改PyPI源，更改后使用`pip`命令安装pip包时速度更快，推荐使用清华大学PyPI软件仓库，可进入网站https://mirrors.tuna.tsinghua.edu.cn/help/pypi/ 按照提示操作。
